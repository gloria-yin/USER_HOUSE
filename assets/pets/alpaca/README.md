# Alpaca Pet Assets

羊驼宠物正式动画资源。三形态为 baby、adult、magic；状态为 normal、happy、eat、sleep、sad。

- 状态图：512 × 128 RGBA PNG，横向 4 帧
- 单帧：128 × 128
- 帧速率：500ms
- 背景：透明
- 灵息特征：白/粉/淡紫/浅蓝云绒、云垫、星月装饰

使用 manifest.json 获取路径和帧信息。CSS 示例：

~~~html
<link rel="stylesheet" href="assets/pets/alpaca/alpaca.css">
<div class="wb-alpaca baby normal"></div>
~~~
