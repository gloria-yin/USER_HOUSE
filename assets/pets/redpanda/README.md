# Red Panda Pet Assets

小熊猫宠物正式动画资源。三形态为 baby、adult、magic；状态为 normal、happy、eat、sleep、sad。

- species key：redpanda
- 状态图：512 × 128 RGBA PNG，横向 4 帧
- 单帧：128 × 128
- 帧速率：500ms
- 背景：透明
- 灵息特征：暗红/黑色，单条环尾从臀部连续长出并保持在身体后方

使用 manifest.json 获取路径和帧信息。CSS 示例：

~~~html
<link rel="stylesheet" href="assets/pets/redpanda/redpanda.css">
<div class="wb-redpanda baby normal"></div>
~~~
