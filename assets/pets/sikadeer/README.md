# Sika Deer Pet Assets

梅花鹿宠物正式动画资源。三形态为 baby、adult、magic；状态为 normal、happy、eat、sleep、sad。

- species key：sikadeer
- 状态图：512 × 128 RGBA PNG，横向 4 帧
- 单帧：128 × 128
- 帧速率：500ms
- 背景：透明
- 灵息特征：金色/白色身体、轻巧金枝角与星点

使用 manifest.json 获取路径和帧信息。CSS 示例：

~~~html
<link rel="stylesheet" href="assets/pets/sikadeer/sikadeer.css">
<div class="wb-sikadeer baby normal"></div>
~~~
